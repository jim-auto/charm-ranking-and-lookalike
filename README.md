# 外見ランキング & 似ている芸能人診断

https://jim-auto.github.io/appearance-ranking-and-lookalike/

芸能人の外見ランキング表示と、自分の写真から似ている芸能人を診断できるサイトです。

## 特徴

- 黄金比ベースの外見スコア算出
- 全身に近い写真での等身推定
- 似ている芸能人マッチング
- すべてブラウザ内で処理（画像はサーバーに送信されません）

## 技術スタック

- Vite + React + TypeScript + Tailwind CSS
- face-api.js（ブラウザ上での特徴量抽出）
- GitHub Pages
